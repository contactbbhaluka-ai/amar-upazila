# আমার উপজেলা: সেটআপ ও প্রকাশের গাইড

উপজেলাভিত্তিক লোকাল সোশ্যাল মিডিয়া ও সেবা ডিরেক্টরি অ্যাপ। একই কোড থেকে **ওয়েব ভার্সন** আর **Android অ্যাপ** দুটোই তৈরি হয়।

**ফিচার:** ফেসবুকের মতো পোস্ট বক্স (একসাথে ১০টি ছবি, বন্ধু ট্যাগ, পাবলিক/বন্ধুরা/শুধু আমি), Instagram-এর মতো ছবি সোয়াইপ, পুরো স্ক্রিনে ছবি দেখা ও সেভ · পোস্টে ৬ রকম রিয়্যাক্ট, আলাদা মন্তব্যের পাতা (সাজানো, রিয়্যাক্ট, পিন), শেয়ার (প্রোফাইল, মেসেজ, Facebook, WhatsApp, লিংক) · ভালুকাকেন্দ্রিক সাইনআপ (ঠিকানা: ভালুকা → পৌরসভা/ইউনিয়ন, অথবা ৬৪ জেলা → ৪৯৫ উপজেলা), মোবাইল নম্বর ও ব্লাড গ্রুপ · ডিরেক্টরিতে স্বয়ংক্রিয় ব্লাড ব্যাংক (নিজের বা অন্যের ডোনার প্রোফাইল হাতে যোগ করার সুবিধাসহ) · ফেসবুকের মতো উপরের মেনু · ☰ মেনুতে সব সেটিং (পাসওয়ার্ড, থিম, ব্লক, অ্যাকাউন্ট মোছা) · পেইজ তৈরি ও ফলো · পাবলিক/প্রাইভেট গ্রুপ (অ্যাডমিন অনুমোদন) · সেভ করা পোস্ট · লেখা ও ছবি পোস্ট · লাইক ও মন্তব্য · ফ্রেন্ড রিকোয়েস্ট ও সাজেশন · ফলো · মেসেজ (সঙ্গে সঙ্গে আসে) · নোটিফিকেশন · মানুষ, পোস্ট ও সেবা একসঙ্গে সার্চ · প্রোফাইল ছবি · ব্লক ও রিপোর্ট · ☰ মেনুতে উপজেলার সব সেবা ও জরুরি নম্বর · অ্যাডমিনের যাচাই

| অংশ | যা ব্যবহার করা হয়েছে | খরচ |
|---|---|---|
| অ্যাপের কোড | HTML + CSS + JavaScript, বিল্ড টুল Vite | ফ্রি |
| ডেটাবেস ও লগইন | Supabase | ফ্রি প্ল্যান |
| Android অ্যাপ | Capacitor | ফ্রি |
| বিল্ড ও ওয়েব হোস্টিং | GitHub Actions ও GitHub Pages | ফ্রি |
| Play Store | Google Play Console | এককালীন ২৫ ডলার |

আপনার কম্পিউটারে কিছু ইনস্টল করার দরকার নেই। সব কাজ ব্রাউজার থেকে করা যায়।

## ফোল্ডারে কী আছে

```
index.html              অ্যাপের মূল পাতা
src/main.js             স্ক্রিন ও বাটনের কাজ
src/api.js              ডেটা লেয়ার (Supabase বা ডেমো মোড)
src/config.js           সেটিংস, ক্যাটাগরি, জরুরি নম্বর
src/style.css           ডিজাইন
public/privacy.html     গোপনীয়তা নীতি (Play Store-এ বাধ্যতামূলক)
supabase/schema.sql     ডেটাবেস তৈরির SQL
assets/                 অ্যাপ আইকন ও স্প্ল্যাশ স্ক্রিন
store/                  Play Store-এর আইকন (512×512) ও ফিচার গ্রাফিক (1024×500)
.github/workflows/      অটোমেটিক বিল্ডের নির্দেশনা
```

> Supabase যুক্ত না করলে অ্যাপ **ডেমো মোডে** চলে। তখন উপরে হলুদ ব্যানার দেখায়, আর ডেটা শুধু ওই ডিভাইসে সেভ হয়।

## ধাপ ১: GitHub-এ কোড রাখা

1. [github.com](https://github.com)-এ অ্যাকাউন্ট খুলুন।
2. উপরে ডানে **+ → New repository** চাপুন। নাম দিন `amar-upazila`, ধরন **Public** রাখুন (GitHub Pages ফ্রিতে পেতে), তারপর **Create repository**।
3. **uploading an existing file** লিংকে ক্লিক করুন। zip খুলে ভেতরের **সব ফাইল ও ফোল্ডার** টেনে এনে ছাড়ুন, তারপর **Commit changes**।
   - ⚠️ `.github` ফোল্ডারটাও আপলোড হতে হবে। Mac-এ লুকানো ফাইল দেখতে Finder-এ `Cmd + Shift + .` চাপুন।

## ধাপ ২: Supabase ডেটাবেস

1. [supabase.com](https://supabase.com)-এ GitHub বা Gmail দিয়ে সাইনআপ করুন, তারপর **New project**।
   - Region: **Southeast Asia (Singapore)**
   - Database password: একটা শক্ত পাসওয়ার্ড দিন এবং কোথাও লিখে রাখুন।
2. বাম মেনু থেকে **SQL Editor → New query** খুলুন। `supabase/schema.sql` ফাইলের পুরো লেখা পেস্ট করে **Run** চাপুন।
   - আগেই schema চালিয়ে থাকলে নতুন করে সব চালাতে হবে না: শুধু `supabase/migrations/2026-11-edit-reply.sql` ফাইলটা চালান (পোস্ট এডিট, মন্তব্য এডিট, উত্তর ও @মেনশন)। তারপর `supabase/migrations/2026-11-cover-albums.sql` (কভার ফটো ও অ্যালবাম)।
   - এতেই সব টেবিল, নিরাপত্তার নিয়ম, ছবি রাখার জায়গা (Storage-এ `media` নামে) আর মেসেজের Realtime চালু হয়ে যাবে।
   - **Storage** মেনুতে `media` নামে একটা bucket দেখা গেলে বুঝবেন সব ঠিকমতো হয়েছে।
3. ভালুকা উপজেলা, ভালুকা পৌরসভা আর ১১টা ইউনিয়ন SQL-এ আগে থেকেই দেওয়া আছে। **Table Editor → services** টেবিলে নমুনা সেবাগুলোর জায়গায় ভালুকার আসল প্রতিষ্ঠান ও ফোন নম্বর দিন (নমুনা নম্বরগুলো `01700-…` দিয়ে শুরু)।
   - জেলা-উপজেলার তালিকা আছে `src/bd-geo.js` ফাইলে। নতুন উপজেলা হলে সেখানে যোগ করবেন।
4. **Authentication → Sign In / Providers → Email** খুলে **Confirm email** বন্ধ করুন। Supabase-এর ফ্রি ইমেইল সার্ভিস ঘণ্টায় খুব কম ইমেইল পাঠাতে পারে, তাই শুরুতে এটা বন্ধ রাখা ভালো।
5. **Project Settings → API**, অথবা উপরের **Connect** বাটন থেকে দুটো মান কপি করুন:
   - **Project URL** (`https://xxxx.supabase.co`)
   - **anon / publishable key**
   - ⚠️ `service_role` বা `secret` key কোথাও দেবেন না।

## ধাপ ৩: GitHub-এ গোপন সেটিংস (Secrets)

রিপোজিটরির **Settings → Secrets and variables → Actions** খুলুন।

**Secrets** ট্যাবে **New repository secret** চেপে এগুলো যোগ করুন:

| নাম | মান |
|---|---|
| `SUPABASE_URL` | ধাপ ২-এর Project URL |
| `SUPABASE_ANON_KEY` | ধাপ ২-এর anon key |

**Variables** ট্যাবে `UPAZILA_ID` = `1` দিন। পরে অন্য উপজেলা যোগ করলে এখানে তার id বসাবেন।

নিজের ডোমেইন থাকলে **Variables**-এ `PUBLIC_URL` = আপনার ওয়েবসাইটের ঠিকানা দিন (যেমন `https://amarupazila.com/`)। শেয়ার করা পোস্টের লিংক এই ঠিকানায় খুলবে। না দিলে GitHub Pages-এর ঠিকানা ব্যবহার হবে।

## ধাপ ৪: ওয়েব ভার্সন প্রকাশ

1. **Settings → Pages → Build and deployment → Source** থেকে **GitHub Actions** বেছে নিন।
2. **Actions → Web deploy → Run workflow** চাপুন।
3. ২-৩ মিনিট পর ওয়েবসাইট চালু হবে এই ঠিকানায়: `https://আপনার-ইউজারনেম.github.io/amar-upazila/`
4. সাইনআপ করে দেখুন। হলুদ "ডেমো মোড" ব্যানার না দেখালে Supabase ঠিকমতো যুক্ত হয়েছে।
5. **নিজেকে অ্যাডমিন বানান** (তাহলে ☰ মেনুতে "অ্যাডমিন ড্যাশবোর্ড" আসবে, যেখানে অ্যাপের সংখ্যা আর "লগইন ছাড়া ডোনারের নম্বর দেখানো" সুইচ আছে): Supabase SQL Editor-এ নিচের লাইনটা চালান। অ্যাডমিন হলে সেবা যাচাই করতে আর যেকোনো পোস্ট মুছতে পারবেন।
   ```sql
   update public.profiles set role = 'admin'
   where id = (select id from auth.users where email = 'আপনার@ইমেইল.com');
   ```

## ধাপ ৫: সাইনিং কি তৈরি (শুধু একবার)

Play Store-এ আপলোড করা প্রতিটি অ্যাপ একটা ডিজিটাল "কি" দিয়ে সাইন করতে হয়।

1. Secrets-এ `ANDROID_KEYSTORE_PASSWORD` নামে একটা শক্ত পাসওয়ার্ড যোগ করুন, আর পাসওয়ার্ডটা নিরাপদে লিখে রাখুন।
2. **Actions → Make upload keystore (one time) → Run workflow** চাপুন।
3. কাজ শেষ হলে পেজের নিচে **Artifacts → upload-keystore** ডাউনলোড করে zip খুলুন।
   - `upload.jks` ফাইলটা আর পাসওয়ার্ডটা Google Drive-এর মতো নিরাপদ জায়গায় রেখে দিন।
4. `keystore-base64.txt` ফাইলের পুরো লেখা কপি করে `ANDROID_KEYSTORE_BASE64` নামে Secret বানান।
5. চাইলে `ANDROID_KEY_ALIAS` = `upload` যোগ করতে পারেন। না দিলেও সমস্যা নেই, এটাই ডিফল্ট।

## ধাপ ৬: Android অ্যাপ বিল্ড

1. **Actions → Android build → Run workflow** চাপুন। প্রথমবার প্রায় ৮-১২ মিনিট লাগে।
2. শেষ হলে **Artifacts** থেকে দুটো ফাইল পাবেন:
   - **app-debug-apk:** ফোনে সরাসরি ইনস্টল করে পরীক্ষা করার জন্য। ফোনে "Install unknown apps" অনুমতি দিতে হবে।
   - **app-release-aab:** Play Console-এ আপলোড করার জন্য।
3. প্রতিবার বিল্ডে versionCode নিজে থেকেই বাড়ে, তাই আপডেট আপলোড করতে কোনো সমস্যা হবে না।

> ⚠️ **প্যাকেজ নাম** `com.amarupazila.app` প্রথমবার Play Store-এ আপলোডের পর আর কখনো বদলানো যাবে না। বদলাতে চাইলে এখনই `capacitor.config.json`-এর `appId` বদলান।

## ধাপ ৭: Google Play Console

1. [play.google.com/console](https://play.google.com/console)-এ অ্যাকাউন্ট খুলুন। এককালীন ২৫ ডলার ফি দিতে হবে আর পরিচয় যাচাই করতে হবে।
2. **Create app** চাপুন। নাম দিন "আমার উপজেলা", ভাষা Bengali, ধরন App, Free।
3. **App content** অংশের ফর্মগুলো পূরণ করুন:
   - **Privacy policy:** `https://ইউজারনেম.github.io/amar-upazila/privacy.html`। তার আগে `public/privacy.html`-এ নিজের ইমেইল বসাতে হবে।
   - **Data safety:** যা সংগ্রহ করা হয়: নাম, ইমেইল, ফোন নম্বর (Phone number), ঠিকানা (Address), ব্লাড গ্রুপ (Health info), ছবি (Photos), মেসেজ (Messages: in-app messages) আর ইউজারের পোস্ট (Other user-generated content)। ডেটা এনক্রিপ্ট করে পাঠানো হয়, কারও সঙ্গে শেয়ার করা হয় না। অ্যাপের ভেতরেই অ্যাকাউন্ট মোছা যায়, আর অ্যাকাউন্ট মোছার লিংক হিসেবে privacy.html-এর ঠিকানা দিন।
   - **Content rating:** প্রশ্নে ইউজাররা একে অপরের সঙ্গে যোগাযোগ করতে পারে (User interaction) কিনা জানতে চাইলে **Yes** দিন।
   - **Target audience:** ১৩ বছর বা তার বেশি বয়স।
4. **Store listing:** `store/` ফোল্ডারের আইকন ও ফিচার গ্রাফিক আপলোড করুন। কমপক্ষে ২টা ফোন স্ক্রিনশট লাগবে, ফোনে অ্যাপ চালিয়ে নিয়ে নিন।
5. **Testing → Closed testing:** নতুন ট্র্যাক খুলে AAB আপলোড করুন। কমপক্ষে **১২ জন টেস্টারের Gmail** যোগ করুন, তাদের টানা **১৪ দিন** যুক্ত থাকতে হবে।
6. ১৪ দিন পর **Apply for production** চাপুন। অনুমোদন পেলে অ্যাপ সবার জন্য Play Store-এ চলে আসবে।

| ডিজাইন, নতুন ফিচার, বাগ ঠিক করা (HTML/JS/CSS) | কোড GitHub-এর main-এ push করুন। Web deploy নিজে চলবে। | অ্যাপ খোলা থাকলে উপরে "নতুন আপডেট এসেছে" দেখায়; পরেরবার খুললে বা কিছুক্ষণ পর ফিরলে নিজে থেকে চালু হয় |
| ডেটা: সেবা, ডোনার, পোস্ট | অ্যাপ থেকেই যোগ/এডিট | সঙ্গে সঙ্গে |
| ফিচার চালু/বন্ধ, ঘোষণা | অ্যাডমিন ড্যাশবোর্ড → অ্যাপ নিয়ন্ত্রণ | সঙ্গে সঙ্গে |
| ডেটাবেসের নিয়ম/নতুন টেবিল | Supabase SQL Editor-এ SQL চালান | সঙ্গে সঙ্গে |
| অ্যাপের আইকন, নাম, পারমিশন, নতুন নেটিভ প্লাগইন | **Actions → Android build** চালিয়ে নতুন AAB Play Console-এ দিন | Play Store আপডেটের পর |

নেটিভ আপডেট দিলে: Play Console-এ নতুন ভার্সন প্রকাশ হওয়ার পর অ্যাডমিন ড্যাশবোর্ডে **সর্বশেষ ভার্সন** বাড়িয়ে দিন (Actions-এর run নম্বরই version code)। পুরনো অ্যাপে "নতুন ভার্সন এসেছে" বার্তা যাবে। খুব জরুরি হলে **সর্বনিম্ন ভার্সন** বাড়ান; তখন পুরনো অ্যাপ আপডেট না করে চলবে না।

> সাবধান: main-এ push করা কোড সঙ্গে সঙ্গে সবার অ্যাপে যায়। বড় পরিবর্তন আগে নিজের ফোনে ওয়েব ভার্সনে দেখে নিন।
> Google Play-এর নিয়মে webview-এর JavaScript এভাবে আপডেট করা চলে, তবে আপডেট দিয়ে অ্যাপকে এমন কিছু বানানো যাবে না যা Play-এর নীতিমালা ভাঙে।
> লাইভ আপডেট বন্ধ রাখতে চাইলে GitHub → Settings → Variables-এ `LIVE_UPDATE` = `false` দিয়ে অ্যাপ বিল্ড করুন।

## নিজের কম্পিউটারে চালাতে চাইলে (ঐচ্ছিক)

Node.js 22 ইনস্টল করে নিচের কমান্ডগুলো চালান:

```bash
npm install
cp .env.example .env   # তারপর .env ফাইলে Supabase-এর মান বসান
npm run dev            # http://localhost:5173
```
